One original line of plain text (at most 200 characters): a review of planet
Earth left by an alien tourist. This entry takes the five-star-or-one-star
extremist angle — one star, because the checkout line took 4,000 years and
the Wi-Fi password is a war crime, even though the oceans are stunning and
the sunsets are free.

`main.py` gates the line (one line, 1–200 characters, not whitespace-only),
writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), reads
it back and verifies it byte-for-byte, exiting non-zero on any gate failure.
